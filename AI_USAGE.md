# AI-assisted development

This project is intentionally developed with extensive use of
AI-assisted software engineering tools.

AI systems may be used for, among other things:

- architecture exploration;
- generation of Terraform and Ansible code;
- documentation;
- tests;
- refactoring;
- code review;
- security analysis.

AI-generated output is treated as untrusted engineering input.

Before inclusion in the project, generated or AI-assisted code is subject
to human review and, where applicable, automated testing, static analysis,
security scanning and license/provenance checks.

The use of AI tooling does not imply that generated output is correct,
secure, original, production-ready or suitable for any particular purpose.
